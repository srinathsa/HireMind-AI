# HireMind-AI 🧠

AI-powered Resume Analyzer that matches your resume with a Job Description.

## What it does
- Paste your Resume + Job Description
- Gets an AI Match Score out of 100
- Shows Missing Skills
- Shows Strengths
- Gives Interview Questions

## How to Run
pip install -r requirements.txt
streamlit run app.py

## Tech Used
- Python
- Streamlit
- Google Gemini AI
